Jetson Orin NX · Arduino Mega 2560 · ROS 2 Humble

pingtung_bot architecture

Every command starts as a ROS 2 topic on the Jetson. mega_bridge turns it into a CRC-checked frame on the USB link, and the Mega drives the actuators.

Data flow, sensor to actuator

  • ROS 2 node in this repo
  • your nodes (teleop, task logic)
  • Mega firmware module
  • hardware
  • ROS topic
  • serial frame

One frame on the wire

Where the wheels stop

wheel_control
no /mega/cmd_vel for 0.5 s
commands 0, or holds the parked heading if idle_hold is on
wheel_control
no IMU for 0.3 s, or gyro still calibrating
commands 0. It never drives without feedback
mega_bridge
no /mega/wheel_pwm for 0.5 s
sends DRIVE 0, 0
Mega firmware
no DRIVE frame for 300 ms (bridge down, cable out)
ramps the brake on and sets wheel_failsafe

The steppers and the servo are not stopped by any of these. They finish the move they were given.
